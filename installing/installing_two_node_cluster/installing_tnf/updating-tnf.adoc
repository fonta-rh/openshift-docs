= Updating a two-node OpenShift cluster with fencing
include::_attributes/common-attributes.adoc[]
:context: updating-tnf

toc::[]

[role="_abstract"]
You update a two-node {product-title} cluster with fencing (TNF) by using the same channels, methods, and procedures as any other {product-title} cluster. Review the TNF-specific behavior before you start an update, so that you can tell expected transient conditions apart from problems that need action.

For update channels, prerequisites, and the update procedure, see "Introduction to OpenShift updates" and "Updating a cluster using the CLI" or "Updating a cluster using the web console".

[IMPORTANT]
====
Start an update only when both control plane nodes are healthy. Do not start an update while the cluster is degraded. For details, see "Prohibited operations during degraded TNF operation".
====
